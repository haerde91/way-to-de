# SQL Learning – Date Functions Exercises

This folder contains short practical exercises focused on working with dates in PostgreSQL.

## Topics practiced

* using EXTRACT()
* extracting year and month from dates
* date arithmetic
* calculating differences between dates
* using DATE_TRUNC()
* grouping data by time periods
* combining date functions with GROUP BY

## Environment

* PostgreSQL
* DBeaver
* pgAdmin
* VS Code
* Ubuntu

## Key takeaway

The main goal was to understand the basic tools available for working with dates and recognize which type of operation is needed for a business problem.

I do not need to memorize every date function or its exact syntax. The important skill is knowing that the functionality exists and being able to look up the syntax when needed.
