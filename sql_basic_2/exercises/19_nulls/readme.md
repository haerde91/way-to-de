# SQL Learning – NULLs Exercises

This folder contains practical exercises focused on handling `NULL` values in PostgreSQL.

## Topics practiced

* using IS NULL and IS NOT NULL
* using COALESCE
* handling missing data with CASE
* working with NULL values in business logic
* maintaining correct query granularity

## Environment

* PostgreSQL
* DBeaver
* pgAdmin
* VS Code
* Ubuntu

## Key takeaway

NULL represents missing or unknown data and requires special handling in SQL.

The main focus was understanding how to identify, replace and classify NULL values in practical business queries.
