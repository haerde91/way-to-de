# SQL Learning – MULTI JOIN exercises

This folder contains exercises focused on combining data from multiple related tables using MULTI JOIN in SQL.

## Topics practiced

- joining multiple tables using multiple JOIN statements
- understanding relationships between multiple entities
- working with complex table connections
- selecting data from different levels of the database structure
- understanding data granularity after joins
- combining JOINs with filtering and sorting

## Environment

- PostgreSQL  
- DBeaver  
- pgAdmin  
- VS Code  

## Notebook

In this section I learned how to build queries using multiple table joins.

These exercises helped me understand how data flows between related tables and how different entities connect inside a relational database.

I also learned that JOIN operations can change the granularity of the result, which is important when creating reports and performing calculations.

## Difficulties

- choosing the right level of data granularity
- avoiding incorrect aggregations after joins
- understanding the difference between order-level and item-level data

These problems were reduced by analyzing table relationships and checking what each row represents after joining tables.

## Key takeaway

A correct JOIN is not only about connecting tables.

The most important part is understanding what each row represents after the join and making sure calculations are performed on the correct level of data.

Understanding data granularity is essential for building reliable SQL reports.
