# SQL Learning – CASE Exercises

This folder contains practical exercises focused on `CASE` expressions in PostgreSQL.

The goal of this section was to learn how to apply conditional logic to SQL queries and classify data based on business rules.

## Topics practiced

* using CASE, WHEN, THEN and ELSE
* creating categories based on numeric values
* handling NULL values with CASE
* using CASE with aggregate functions
* conditional aggregation with SUM() and COUNT()
* combining CASE with GROUP BY
* maintaining correct query granularity

## Environment

* PostgreSQL
* DBeaver
* pgAdmin
* VS Code
* Ubuntu

## Key takeaway

CASE is useful when SQL needs to apply conditional business logic.

The main focus was not memorizing the syntax, but understanding when conditional logic is needed and how it affects the result.

I also practiced combining CASE with aggregation to create business metrics and customer segments.
