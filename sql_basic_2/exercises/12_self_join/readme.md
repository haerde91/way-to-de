# SQL Learning – SELF JOIN exercises

This folder contains exercises focused on comparing records within the same table using SELF JOIN.

## Topics practiced

- joining a table with itself using aliases
- comparing records from the same table
- finding related pairs of records
- avoiding duplicate pairs
- using comparison conditions between rows
- understanding business-defined relationships

## Environment

- PostgreSQL
- DBeaver
- pgAdmin
- VS Code

## Notebook

In this section I learned how SELF JOIN works and how the same table can be used multiple times in one query.

These exercises helped me understand that relationships in SQL are not always only based on foreign keys. They can also be created by business logic, such as comparing products from the same category or orders from the same customer.

## Difficulties

- understanding the business meaning of comparing two records


## Key takeaway

SELF JOIN allows comparing rows inside the same table.

The most important skill is understanding what relationship should be created between records based on the business requirement.
