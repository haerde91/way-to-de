# SQL Learning – INNER JOIN exercises

This folder contains focused exercises on combining related tables using INNER JOIN in SQL.

## Topics practiced

- joining multiple tables using `INNER JOIN`
- understanding relationships between tables (1-to-many, many-to-many)
- using foreign keys in joins
- building queries across multiple entities
-selecting relevant columns from multiple tables
- avoiding unnecessary joins

##Environment

- PostgreSQL  
-DBeaver  
- pgAdmin  
- VS Code  

## Notebook

In this section I learned how to retrieve data from multiple related tables using INNER JOIN.

These exercises helped me understand how relational databases are structured and how data is connected through keys.

I also practiced how to move from a single-table mindset to multi-table querying, which is essential for data engineering.

## Difficulties


- accidental data duplication caused by joins
- mixing up primary keys and foreign keys
- selecting correct level of granularity in results

These problems were reduced by practicing step-by-step join building and testing intermediate results.

## Key takeaway

INNER JOIN returns only matching records between tables.

Understanding table relationships is more important than memorizing SQL syntax.

The most important skill is knowing how data flows between tables.
