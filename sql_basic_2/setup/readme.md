## Database Setup

For this stage I use a small e-commerce database created for training purposes.

### Tables

**customers**

* customer information
* customer_id, customer_name, city

**orders**

* customer orders
* order_id, customer_id, order_date, amount

**products**

* product catalog
* product_id, product_name, category, price

**order_items**

* links orders with products
* contains purchased quantities

These tables allow practicing real SQL relationships, data modeling concepts, and query patterns commonly used in Data Engineering projects.

## Data Source

The database schema and sample data were generated with ChatGPT for educational and training purposes only.

The dataset is fictional and does not represent real customers, products, or transactions.

## Environment

* PostgreSQL
* DBeaver
* VS Code
* pgAdmin

## Goal

Build strong SQL foundations for a future Data Engineering career by working with relational databases, understanding table relationships, and writing increasingly complex queries.
