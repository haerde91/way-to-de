# SQL Learning – basic_sql2 (Joins & Relational Data)

This folder contains exercises focused on working with multiple tables and learning relational SQL concepts.

## Topics to be practiced

- `INNER JOIN` for combining related tables
- `LEFT JOIN` for keeping all rows from the left table
- understanding primary and foreign keys
- working with relational data models
- joining tables using shared identifiers (e.g. `id`, `*_id`)
- combining JOINs with:
  - `WHERE` filtering
  - `GROUP BY` aggregation
  - `HAVING` filtering grouped results
  - `ORDER BY` sorting results

## Environment

- PostgreSQL  
- DBeaver  
- pgAdmin  
- VS Code  

## Notes

In this section I will move from single-table analysis to relational data models.

The main focus is understanding how tables connect to each other and how SQL behaves when data is split across multiple sources.

I will also start combining JOINs with aggregation and filtering to simulate real analytical queries.

## Difficulties expected

- understanding how tables are connected through keys
- choosing correct join type (`INNER` vs `LEFT`)
- avoiding duplicated rows caused by joins
- combining JOIN logic with aggregation (`GROUP BY`, `HAVING`)
- reading query results from multiple tables at once

## Key takeaway

SQL becomes more powerful when working with relational data. JOINs allow combining different datasets into one analytical view, which is a core skill in data engineering.
