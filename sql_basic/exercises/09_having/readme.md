# SQL Learning – HAVING exercises

This folder contains exercises focused on filtering aggregated results in SQL using the `HAVING` clause.

## Topics practiced

- `GROUP BY` with aggregated data
- filtering grouped results using `HAVING`
- combining aggregates like `COUNT`, `AVG`, `MIN`, `MAX`
- `COUNT(DISTINCT column)` for unique values

##Environment

- PostgreSQL  
- DBeaver  
- pgAdmin  
- VS Code  

## Notebook

In this section I learned how to filter results after grouping data.


This required combining multiple SQL concepts in one query, which made the logic more complex than previous sections.

## Difficulties

- incorrect placement of aggregate functions
- problems with `COUNT(DISTINCT column)`
- difficulty combining multiple conditions in grouped queries
- logical thinking about grouped data vs single rows

These were improved through practice and testing queries step by step.

## Key takeaway

HAVING is used to filter groups after aggregation.
SQL queries require understanding the order of execution, not only syntax.
