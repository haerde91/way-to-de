# SQL Learning – GROUP BY & HAVING exercises

This folder contains exercises focused on grouping data and filtering aggregated results in SQL.

## Topics practiced

- `GROUP BY` for aggregating data per category
- combining multiple aggregate functions
- `COUNT(*)` vs `COUNT(column)`
- `COUNT(DISTINCT column)` for unique values
- `HAVING` for filtering aggregated results
- ordering grouped results with `ORDER BY`

## Environment

- PostgreSQL  
- DBeaver  
- pgAdmin  
- VS Code  

## Notes

In this section I started learning how to work with grouped data instead of single rows.

I also noticed that SQL requires a clear structure when combining multiple conditions, especially when using aggregation functions like `COUNT(DISTINCT ...)`.

Some patterns are still not fully automatic, especially when mixing `GROUP BY` with multiple conditions and different types of aggregation.

## Difficulties

- confusion when using multiple conditions together
- remembering syntax for `COUNT(DISTINCT column)`
- initial use of `HAVING` before fully learning it

These were improved through practice and testing queries step by step.

## Key takeaway

GROUP BY is about organizing data into groups, while HAVING is used to filter those groups after aggregation.
