# SQL Learning – DISTINCT exercises

This folder contains exercises focused on working with unique values using `DISTINCT` in PostgreSQL.

## Topics practiced in this section

- extracting unique values from a single column
- finding unique combinations of columns
- using `DISTINCT` with `ORDER BY`
- combining `DISTINCT` with `WHERE` filtering

## Environment

Exercises were solved manually in a local PostgreSQL environment using:

- PostgreSQL
- DBeaver
- pgAdmin
- VS Code

## Learning notes

In this section I learned that `DISTINCT` is used to remove duplicate rows from query results and works on the full row, not individual columns.
