# SQL Learning – LIKE / ILIKE exercises

This folder contains exercises focused on text filtering in SQL using `LIKE` and `ILIKE`.

## Topics practiced

- pattern matching with `LIKE`
- case-insensitive search with `ILIKE`
- wildcards `%` and `_`
- combining conditions with `AND` / `OR`

## Environment

- PostgreSQL  
- DBeaver  
- pgAdmin  
- VS Code  

## Notes

In this section I learned how to search inside text instead of using exact matches.

I also noticed that SQL treats text as a single string, so assumptions like “name and surname” must be handled carefully.

## Difficulties

- confusion about how `_` and `%` work
- mixing logic with `AND` / `OR` without parentheses
- incorrect assumptions about structure inside text fields

These were solved by testing queries and checking results step by step.

## Key takeaway

LIKE is for pattern matching, not for understanding data structure. SQL follows strict logic, so conditions must be written carefully.
