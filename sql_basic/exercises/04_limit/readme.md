# SQL Learning – LIMIT exercises

This folder contains exercises focused on limiting and controlling query results using `LIMIT` and `OFFSET` in PostgreSQL.

## Topics practiced in this section

- limiting number of returned rows (`LIMIT`)
- skipping rows (`OFFSET`)
- basic pagination concepts
- selecting top results
- combining `LIMIT` with `ORDER BY` and `WHERE`

## Environment

Exercises were solved manually in a local PostgreSQL environment using:

- PostgreSQL
- DBeaver
- pgAdmin
- VS Code

## Learning notes

During this section I learned that `LIMIT` is very useful for:

- debugging queries (viewing a small sample of data instead of large datasets)
- quickly inspecting table structure and content
- selecting top records from a dataset
- basic query performance control (reducing unnecessary output during development)

## Learning process

All tasks were solved independently and later reviewed with ChatGPT for feedback and verification.
