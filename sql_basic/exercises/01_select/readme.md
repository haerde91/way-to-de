# SQL Learning – SELECT exercises

This folder contains exercises focused on basic SQL SELECT operations using a PostgreSQL database (`nobel` table).

## Dataset

The dataset is a simple training table `nobel`, containing information about Nobel Prize winners:

- yr (year)
- subject (field)
- winner (name of laureate)

## Scope of exercises

This section covers:

- basic SELECT queries
- selecting single and multiple columns
- column aliasing
- basic expressions in SELECT
- string functions (e.g. length)
- DISTINCT usage
- ORDER BY sorting

## Learning approach

All tasks were solved manually in a local PostgreSQL environment (DBeaver / pgAdmin).

During the learning process:

- SQL concepts and query logic were solved independently
- PostgreSQL documentation was used when needed to find specific functions
- ChatGPT was used as a support tool for discovering function names or syntax when necessary
- The final implementation and query logic were deduced and understood independently

## Goal

The goal of this section is to build a strong foundation in SQL by:

- understanding query structure
- practicing data selection and transformation
- developing SQL problem-solving intuition
