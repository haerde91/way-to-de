# SQL Learning – ORDER BY exercises

This folder contains exercises focused on sorting data using `ORDER BY` in PostgreSQL.

## Topics practiced in this section

- sorting ascending and descending
- sorting by multiple columns
- combining `WHERE` with `ORDER BY`
- sorting by calculated values
- building more realistic SQL queries

## Environment

Exercises were solved manually in a local PostgreSQL environment using:

- PostgreSQL
- DBeaver
- pgAdmin
- VS Code

## Learning process

All tasks were solved independently and later reviewed with ChatGPT for verification and feedback.
